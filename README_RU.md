# SteadySurvivor v6 — эксперимент по времени входа в зону

За основу взят **исходный v1 (2,27 балла)**, а не v5.

**Одно игровое изменение:** робот перестал автоматически идти к следующему кругу с первых секунд матча. Он рассчитывает, сколько времени осталось до окончания сужения, и учитывает необходимый путь. Срочное отступление от противников и выход из текущей опасной зоны работают как в v1. Оружие, прицеливание, подбор предметов не менялись.

Идея: не привлекать внимание всей команды встроенных противников ранним движением к центру. Плюс или минус по очкам будет понятен **только после нового сабмита**.

### Проверка

```bash
python3 test_strategy.py
bash test_official.sh
bash test_docker.sh
```

`test_official.sh` проверяет формат и скорость ответов, но не победы в реальных матчах.
