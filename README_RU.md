# SteadySurvivor v2 — инструкция

v1 уже получил **2.27 очка** за 48 тренировочных матчей. v2 — экспериментальное обновление: пока подтверждена только техническая корректность, а не прирост игрового рейтинга.

## Что изменилось

1. **Навигация по карте:** бот читает `world.json` из `hello.map.dir` и создаёт приближённую карту непроходимых зданий. Для маршрута использует A* порциями, чтобы не пропускать ответы за 50 мс.
2. **Отступление:** фиксирует точку ухода от врага на несколько игровых секунд, вместо постоянного изменения цели.
3. **Обзор:** непрерывно поворачивает торс на 360° при отсутствии противника; учитывает направление входящего урона.
4. **Улучшения:** выбирает из реальных ID организаторов (`nanites`, `armor`, `plating`, `servos`, …).
5. **Управление ресурсами:** пересмотрена частота ускорений и проверка высоты оружия для подбора.

Навигация упрощённая: крыши, мосты, уклоны и движущиеся препятствия моделируются не полностью. Проверка `PASS` не доказывает, что итоговый скор выше 2.27.

## Тесты на Mac

Положи папки `mechfight-kit` и `SteadySurvivor_Submission_v2` рядом внутри `Downloads`.

```bash
cd ~/Downloads/SteadySurvivor_Submission_v2
python3 smoke_test.py
bash test_official.sh
bash test_docker.sh
python3 test_strategy.py
```

При `PASS` загрузи обновлённый `example_bot.py` на GitHub (либо смержи PR, если он создан), отправь ссылку репозитория повторно в Mech Royale и сравни результаты. Обязательно сохрани v1 для отката, если v2 окажется слабее.
