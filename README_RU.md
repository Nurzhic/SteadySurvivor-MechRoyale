# SteadySurvivor v4 — эксперимент с совместным огнём

**База: v1 (2,27 очка)**, а не v2/v3. Мы намеренно изменили только один
участок боевого алгоритма, чтобы сравнение было понятным.

## Изменение
Когда бот атакует лазером или молнией, он также стреляет из основной
пушки, если траектория подходит: цели хватает дальности, патроны есть,
перезарядки нет, прицел достаточно совмещён с траекторией пули.
При выстреле миномётом дополнительная стрельба отключена: у миномёта
совсем другой баллистический угол.

Логика перемещения, выбора целей, сбора ресурсов и усилений совпадает
с v1. Цель эксперимента — повысить урон по одному врагу, быстрее
устранять противников и улучшить место в тренировочных боях.

## Проверка
Распакуйте официальный комплект `mechfight-kit` рядом с этой папкой.
```sh
python3 test_strategy.py
python3 smoke_test.py
bash test_official.sh
bash test_docker.sh
```

`PASS` означает соответствие протоколу, но не гарантирует рост очков.
Для сравнения нужен официальный score v4.

Публичный репозиторий необходимо сохранить, а для возможности отката
следует сохранить commit/tag версии v1 с лучшим score 2,27.
