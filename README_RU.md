# SteadySurvivor v5 — реакция на попадания

Эксперимент от **v1 (лучший score 2.27)**, без наследования изменений v2–v4.

Одно основное изменение: по событию `damaged` с направлением попадания бот в течение 2 секунд уходит от источника урона по диагонали, включает ускорение при доступной энергии и разворачивает корпус к источнику, если нет видимой цели. На время опасности приостанавливает сбор лута. Выход из опасной зоны остаётся приоритетным.

Улучшение score НЕ гарантировано. Тесты протокола не моделируют настоящие матчи.

## Проверка

```sh
python3 test_strategy.py
bash test_official.sh
bash test_docker.sh
```

Команды предполагают, что `mechfight-kit` находится рядом с папкой проекта. После PASS можно обновить GitHub и отправить повторно.
